How it behaves

1

Agent reads

Each route exposes a validated projection of the same bounded state already visible to the person.

2

Agent narrows

Search and queue scope can change for clarity, while every denominator remains explicit.

3

Agent prepares

Workers can add bounded Draft work, then prepare a next action whose evidence note comes from verified workspace facts.

4

Person decides

Approve and save the proposal, edit it, or discard it. Consequential authority never moves into the tool.

Built to be checked

The contract is visible in the product.

Exact denominators

Workspace, matching, shown, and remaining counts travel with each bounded view.

Evidence beside priority

Review explains why each work item surfaced using the same reasons exposed to the agent.

Visible page receipts

Agent-driven scope and preparation report what changed and explicitly say workspace data did not.

Stale-safe preparation

Next rejects a proposal if the editor no longer matches the state the agent most recently read.

Scope: Public static sample, no login, no backend, and five focused workflow pages. WebMCP can add at most three browser-local Draft items at once; only visible human controls can Start work or approve a final Save.
